# Day 26 – Prior Authorization Workflow Simulator

## Prior Authorization Workflow Simulator

An interactive, gamified web application that simulates the U.S. Healthcare Prior Authorization (PA) process using drag-and-drop interactions. The simulator demonstrates how patient cases move through the Patient, Provider, and Payer workflow while educating users about each stage.

---

# Project Overview

This project was built as part of the **#60DaysChallenge** to improve frontend development skills while creating a realistic healthcare workflow simulation.

### Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Responsive Design
* Drag-and-Drop API

---

# Features

* Interactive drag-and-drop workflow
* Three workflow lanes

  * Patient
  * Provider
  * Payer
* Multiple patient scenarios
* Medical Necessity Evaluation
* Prior Authorization document collection
* Submission to payer
* Review outcomes

  * Approval
  * Pend
  * Denial
  * Appeal
  * Peer-to-Peer Review
* Educational explanations after every stage
* Progress tracker
* Days elapsed counter
* Efficiency score
* Celebration animation
* Workflow completion summary
* Restart / New Patient functionality
* Fully responsive UI
