# Day 50 – Defend Your Experience

## 📌 Challenge
Built **Defend Your Experience**, an AI-powered interview preparation application that helps users confidently defend every claim made in their resume, portfolio, LinkedIn profile, or professional experience.

## 🎯 Objective
Create an adaptive interview system that:
- Extracts meaningful claims from uploaded documents.
- Challenges users with personalized follow-up questions.
- Simulates realistic recruiter interviews.
- Tracks confidence and progress.
- Generates a comprehensive Defense Report.

## 🚀 Features
- AI-powered adaptive interview experience
- Personalized follow-up questions
- Resume & portfolio claim extraction
- Confidence score tracking
- Progress dashboard
- Defense Report generation
- Session history
- Local storage support
- Drag & Drop document upload
- Responsive premium UI
- Export functionality
- Graceful API error handling

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- Anthropic Messages API
- Local Storage
