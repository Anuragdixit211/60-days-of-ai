# Day 37 - Claude Challenge 🚀

## Project Title

**Task Compass – Learn How Work Flows Through Real Organizations**

## Objective

Built a premium single-file offline web application that teaches how work flows through organizations using an interactive management simulation. The application focuses on ownership, delegation, collaboration, escalation, and workflow thinking instead of traditional quiz-based learning.

## Features

* Single HTML file (Offline)
* HTML, CSS & Vanilla JavaScript
* Responsive Glassmorphism UI
* Dark Mode Design
* Animated Gradients
* Drag & Drop Interactions
* Three Interactive Game Stages
* Progress Tracking
* Understanding-based Evaluation
* Animated Workflow Visualization
* Final Reflection Dashboard
* Responsive Design
* No External Libraries or APIs

## Stages

### Stage 1 – Who Owns This?

* Identify the primary owner of realistic workplace tasks.
* Learn ownership reasoning.
* Discover supporting roles.

### Stage 2 – Task Routing

* Arrange how work moves through different teams.
* Learn organizational workflows.
* Visual workflow animation.

### Stage 3 – Collaboration Challenge

* Handle larger workplace scenarios.
* Select primary owner and supporting teams.
* Understand communication flow.

## Key Learnings

* Ownership is about accountability, not job titles.
* Delegation helps teams work efficiently.
* Complex problems require collaboration across multiple departments.
* Workflow thinking improves decision-making.
* Escalation is a normal part of organizational success.
* Effective communication keeps projects moving smoothly.
* Real-world organizations solve problems through teamwork rather than individuals.
