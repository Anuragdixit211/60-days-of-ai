Day 51 – Product Discovery & Sprint Planning

Project Summary

Working Name: Placemate AI

Placemate AI is a web application for college students preparing for campus placements. Users invite a friend, prepare together, chat through a refresh-based messaging system, set daily study goals, mark them complete, track shared progress, and use an AI Placement Mentor for interview preparation (DSA, DBMS, OS, Aptitude, HR, Resume). The MVP is intentionally focused on improving consistency through accountability and is designed to be completed and deployed within 10 days.

Product Requirements Document (PRD)

Problem

Placement preparation is inconsistent because students often study alone and lack accountability.

Target Users

  • College students preparing for campus placements.

Goals

  • Increase daily study consistency.
  • Provide peer accountability.
  • Offer AI placement guidance.

Core Features

  • User Authentication
  • Invite Friend via Code
  • Buddy Connection
  • Refresh-based Chat
  • Daily Study Goals
  • Goal Completion Tracking
  • Shared Progress Dashboard
  • AI Placement Mentor
  • Responsive Web UI

Out of Scope

  • Video/Voice Calls
  • AI Buddy Matching
  • Group Study Rooms
  • File Sharing
  • Push Notifications
  • Premium Features

Success Criteria

Live deployed MVP with two connected users, working chat, accountability workflow, AI mentor, and responsive UI.
