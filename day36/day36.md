# Day 36 - Cognitive Pattern Explorer

## 📅 Date

06 July 2026

## 🚀 Project Title

**Cognitive Pattern Explorer**

## 📌 Objective

Built a single-file offline web application that provides a psychology-inspired self-reflection experience through interactive scenarios. The application encourages users to explore their thinking patterns in a calm, game-like environment while clearly stating that it is educational only and not a diagnostic tool.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## ✨ Features

* Responsive single-page application
* Interactive reflection scenarios
* Calm and minimal UI
* Progress tracking
* Educational insights based on user choices
* Smooth animations and transitions
* Offline functionality
* No external libraries or frameworks

* Improved skills in creating responsive single-file web applications.

* Understood the importance of using reflective, non-diagnostic language in psychology-inspired applications.
