**ABTalks – 60 Days Claude AI Mastery Challenge**

## 🚀 Project Title

**Content Intelligence Studio – AI-Powered Content Analysis Platform**

## 📖 Project Overview

Today, I built **Content Intelligence Studio**, a premium single-page HTML application that acts as an AI content consultant. The application is designed to analyze both text and image-based content using a multi-stage AI review workflow powered by the Claude Messages API.

The platform provides detailed insights, content scoring, platform-specific recommendations, rewritten content, optimized hooks and titles, publishing checklists, AI reasoning, and a comprehensive executive report—all within a modern SaaS-style interface.
