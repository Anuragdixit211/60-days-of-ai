What this tool is for

This is your personal library of reusable AI prompt workflows — editable templates for things you do often as a developer (like debugging, explaining code, or writing PRs) so you're not retyping instructions to Claude from scratch every time. Use Dashboard to see everything at a glance, All Workflows to browse and search, the Prompt Builder to assemble a one-off prompt from labeled building blocks, and the Loop Builder to turn any prompt into a self-checking, repeating instruction set for Claude to iterate on until a goal is met.

Loop Builder

Turns any normal prompt into an autonomous looping prompt — instructions telling Claude to keep checking and improving its own answer against criteria you set, instead of stopping after one try. Useful for things like "keep debugging until the test passes" or "keep refactoring until it meets these standards."

1. Base prompt 2. Goal 3. Evaluation criteria 4. Improvement strategy 5. Stop conditions 6. Safety rules
Base prompt ⓘThe core task you want done, e.g. "Find why this API call returns a 500 error." The loop wraps around this task.
The task itself — what you want Claude to actually do.
Goal ⓘThe end state that defines success. Without a clear goal, a loop has no direction and won't know what "done" looks like.
What "success" looks like when the loop is finished.
Evaluation criteria ⓘHow Claude should judge each attempt before deciding whether to try again. Concrete, checkable criteria stop the loop from guessing.
How each attempt should be judged, in checkable terms.
Improvement strategy ⓘWhat Claude should do differently on the next pass if the current attempt fails evaluation, so each iteration actually makes progress.
What to change or try next if an attempt doesn't pass.
Stop conditions ⓘWhen the loop must end — either because it succeeded, or as a safety limit so it doesn't run forever on an unsolvable problem.
When the loop should stop, whether it succeeded or not.
Safety rules ⓘGuardrails so an autonomous loop doesn't do something risky while trying to reach the goal, like running destructive commands or making unrequested changes.
Guardrails so the loop doesn't take risky action while iterating.

What is this?

A quick orientation to the Debug-First AI Playbook

This is a personal library of reusable AI prompt workflows, built around how developers actually work — especially debugging. Instead of retyping instructions to Claude every time, you save templates once and reuse them with small edits.
