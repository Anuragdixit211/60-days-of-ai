System Prompt Design
The AI is constrained to act as a fresher-focused ATS analyst and recruiter-style coach. It uses a strict JSON contract, evidence-based scoring, missing-information handling, prompt-injection resistance, and safe abuse handling.
Purpose-Built UI
A score dial gives instant orientation; section bars expose resume health; keyword chips reveal JD gaps; prioritized fix cards convert analysis into action. This is intentionally not a generic chat box.
