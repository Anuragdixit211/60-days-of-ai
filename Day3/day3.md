# Day 3 - Role-Based Prompting

## Objective

To understand how assigning a role to AI improves the quality of responses.

## Prompt Used

### Basic Prompt

Explain Prompt Engineering.

### Role-Based Prompt

You are an AI educator teaching complete beginners.

Explain Prompt Engineering in simple language.

Include:

* What Prompt Engineering is
* Why it matters when using AI tools like Claude
* One example of a weak prompt
* One example of an improved prompt
* Three practical benefits of writing better prompts

## Output Summary

The role-based prompt generated a more structured, detailed, and beginner-friendly explanation compared to the basic prompt.

## Key Learnings

* Assigning a role improves response quality.
* AI provides more relevant and targeted outputs.
* Clear instructions reduce ambiguity.
* Structured prompts produce professional results.
